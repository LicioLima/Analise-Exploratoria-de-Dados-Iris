# Analise-Exploratoria-de-Dados-Iris
Projeto de Fundamentos em Engenharia de Dados como consultor principal da Dados Mágicos Ltda. Realizei Análise Exploratória (EDA) completa com Python, Pandas e Seaborn no dataset Iris . O foco foi gerar insights de negócio via correlação de Pearson, boxplots e histogramas, aplicando conceitos de Modern Data Stack e Manifesto Ágil
